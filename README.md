# Tropas 40k

Aplicativo Android para **montar e consultar listas de exército de Warhammer 40,000 (11ª edição)**, feito por e para um grupo de amigos que joga junto.

> **Uso pessoal e entre amigos, para jogos amistosos.** Não é um produto comercial, não é vendido e não tem relação com a Games Workshop. Para torneios e eventos oficiais, use as publicações e o app oficial da Games Workshop.

## Para que serve

- **Montar listas (Edit):** escolher facção, tamanho de jogo e detachments; adicionar unidades, configurar modelos e armas (com os stats de cada opção), anexar líderes e escolher enhancements. A lista é validada enquanto você monta: pontos, Detachment Points, limites de cópias e de enhancements.
- **Jogar (Play):** fichas no formato de datasheet de cada unidade, unidades com líder abertas juntas, estratagemas por fase com filtro de turno e as regras core (com o livro de Core Rules para consulta, offline).
- **Importar e exportar:** importa o texto exportado pelo app oficial e o texto exportado pelo próprio Tropas 40k.
- **Listas em todos os seus aparelhos:** com a chave do clube, as listas sincronizam entre os seus celulares.

O app é em inglês, como os livros e o app oficial.

## Para quem é

Para os membros do clube e amigos que jogam juntos. O acesso é por uma **chave pessoal** dada pelo clube (quando o clube estiver exigindo chave). Se você não é do grupo, este app não é para você.

## Como instalar

1. No celular Android, abra a página de [releases](../../releases/latest) e baixe o arquivo `Tropas40k-….apk`.
2. Abra o arquivo baixado. Se o Android perguntar, permita **instalar apps desta fonte** e confirme. O Android pode avisar que o app não vem da Play Store; é esperado.
3. Abra o app e, se ele pedir, digite a chave que você recebeu do clube.

Depois disso o app se atualiza sozinho: quando sai uma versão nova, ele avisa e aplica com um toque. Suas listas continuam.

Só a versão mais recente fica disponível aqui. Os arquivos "Source code" que o GitHub mostra em cada release contêm apenas este README.

## De onde vêm os dados

- **[BSData](https://github.com/BSData/wh40k-11e)** (projeto da comunidade): unidades, pontos, armas, habilidades, detachments e enhancements.
- **[Wahapedia](https://wahapedia.ru)**: estratagemas e o texto do livro de Core Rules, que o BSData não tem.

Os dados são atualizados automaticamente quando essas fontes mudam. Podem conter erros: na dúvida, vale o material oficial.

## Privacidade

O servidor do clube guarda apenas o necessário para o app funcionar: nome do membro, a chave (para validação), os aparelhos ligados a ela e as listas que você sincroniza. Nada é vendido nem compartilhado.
